## The lesson these represent

Four reference sets in ten days, and the failure was the same each time: **front-on only, and lit
for mood rather than for measurement**. The set that finally worked was asked for explicitly —
flat light, plain background, true 90° profile, mouth open — rather than harvested from footage
that happened to exist.
